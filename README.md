# C++ Student Management System

A menu-driven student management system developed in C++ for maintaining student records.

## Features

- Add student records
- Search student records
- Edit student records
- Delete student records
- Display student records
- Store student data using file handling

## Student Information

The system manages:

- Name
- Roll number
- Age
- Marks

## Concepts Used

- C++ functions
- File handling
- Structures/classes
- Conditional statements
- Loops
- Basic data management
